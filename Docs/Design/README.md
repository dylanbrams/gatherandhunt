# Design Docs

Put GatherAndHunt design documentation here.

Suggested contents:

- gameplay rules
- board and piece behavior
- save/load design
- UI flow notes
- technical design decisions
- single-player act structure: `SinglePlayerActs.md`
- turn planner and board editor UI (how to launch, controls, preview, editing boards): `PlannerUI.md`
- C++ replacements for the retired Blueprints, how the old level system worked, and the level import: `PuzzleHookupImplementation.md`
- ship art (skins, the frame-cycle material, the art preview, importing a new drop): `ShipArt.md`
- level select map (flying the ship to levels, the moves and motions it earns, authoring the map): `LevelSelect.md`
- input (Input Actions built in C++, keyboard and gamepad defaults, custom controls): `Input.md`
- multiplayer turn loop (phases, playback acks, match end): `MultiplayerTurnLoop.md`
